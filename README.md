# Language Meaning TTS Advanced

A multi-language audio tool designed for language learners to memorize vocabulary.

* Traditional online TTS reads words in one language, and may cost you 💸 money and ⛔ limit your use.
* Language Meaning TTS Advanced costs you zero💲, pronounces in two languages, and creates an instant audio reflex in your brain.

## 🎯 Core Concept & The Brain Reflex Method

It plays your familiar language first, followed immediately by the foreign word.<br>
You can make the words repeat as many times as you want and set your preferred pause length.

### 🎧 How the Audio Flow Works (Examples)

* **English speaker learning French:**
  > 🔊`"abandon"` ➔ ⏱️ *Pause* ➔ `"abandonner, renoncer"`<br>
  > 🔊`"escape"` ➔ ⏱️ *Pause* ➔ `"s'echapper, fuir"`<br>
  > 🔊`"finish"` ➔ ⏱️ *Pause* ➔ `"finir, achever"`

* **Spanish speaker learning Italian:**
  > 🔊 `"sueño"` ➔ ⏱️ *Pause* ➔ `"il sogno"`<br>
  > 🔊 `"escapar"` ➔ ⏱️ *Pause* ➔ `"scappare"`<br>
  > 🔊 `"terminar"` ➔ ⏱️ *Pause* ➔ `"finire"`

### 💡 Practical Design & Workflow
1. **Audio-First Learning:** Listen to your vocabulary anytime, anywhere without staring at a screen.
2. **Instant Mapping:** Hear the meaning right before the foreign word to link them together.
3. **Continuous Playback:** Converts your text list into a single audio file for non-stop listening.


## ✨ Features

* **🔒 100% Offline & Free:** Runs completely locally on your CPU. Consumes zero online tokens, API keys, or internet data.

* **🌍 32 Languages Supported:** No need to install any language pack on your computer.

* **🔄 Any Language Pair Combination:** Dual drop-down lists let you pick any two of the 32 languages (e.g., English ➔ German, Spanish ➔ Italian, Chinese ➔ Japanese, Hindi ➔ French).

* **🎛️ Full Control Over Speed, Repetition & Pause:** Customize playback speed, set how many times each word repeats, and adjust the exact pause duration between words.

* **⚡ Zero-Setup Portable Application:** Just unzip and run the EXE, paste your vocabulary list, select the voices, and export an audio file.


## 📥 How to Use (Choose Your Option)

### Option 1: If you just want to study by yourself
* 📥 Download the **"Language Meaning TTS Advanced (Windows).zip"** under the 📂 "executable" folder, decompress the zip file and run **"Language Meaning TTS Advanced.exe"** directly. 

> ℹ️ **Note:** Currently fully tested for Windows. The macOS version remains untested.

### Option 2: If you want to modify or compile the program 

🧑‍💻 Compile the executable file on Windows:
1. Open PyCharm terminal in the project root directory and run:
```bash
.\.venv\Scripts\python.exe -m PyInstaller --clean --noconsole --onedir --icon=language_meaning_tts_advanced_icon.ico --collect-all sherpa_onnx --collect-all soundfile --collect-all sounddevice --hidden-import=scipy.signal --hidden-import=pythoncom --add-data "language_meaning_tts_advanced_icon.ico;." --add-data "ffmpeg-8.0-essentials_build/bin/ffmpeg.exe;ffmpeg-8.0-essentials_build/bin" --add-data "tts_models;tts_models" main.py
```
2. Find your standalone application in the `dist` folder.
